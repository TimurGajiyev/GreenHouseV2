- **ЖКПЗ — один завод, две машины: Жаркент (TEDOM Quanto 1200) и Жаркент 2 (Jenbacher,
  логгер CC42).** Импорт по вводу ЖКПЗ в выгрузке дашборда — это сетевой счётчик логгера CC42
  (медианное расхождение 6,5 кВт), а потребление ЖКПЗ = TEDOM + заводской счётчик CC42
  (6,4 кВт). Часы у дашборда и CC42 совпадают. Заводской счётчик CC42 показывает завод
  **без** TEDOM.
- **Жаркент 3 (логгер CR06) — отдельный завод**: с ЖКПЗ не коррелирует ни при каком сдвиге.
- Что CC42 = Жаркент 2, а CR06 = Жаркент 3, по-прежнему выведено из моточасов.

## Что из этого следует для расчёта

- Все три типа машин по паспорту работают **от 50 % номинала**. Правило 90 % у
  производителя не встречается — это ограничение из модели CHP_BESS_model_v2.xlsx
  («KILLER — нужна режимная карта»), а не из документации.
- Кривые КПД выше — настоящие данные для частичной нагрузки (в калькуляторе пока
  стоит одна цена за кВт·ч, без зависимости от загрузки).
